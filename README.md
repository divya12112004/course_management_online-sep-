# 🎓 CourseHub – Online Course Management System

CourseHub is a full-stack online course management system that allows students to explore courses, register and log in securely, enroll in courses, track learning progress, and manage their profiles.

The system also provides an admin dashboard for managing courses, students, enrollments, and platform statistics.

## ✨ Features

### 👨‍🎓 Student Features

- User registration and login
- JWT-based authentication
- Browse available courses
- Search courses
- Filter courses by level
- Filter courses by category
- View course details
- Enroll in courses
- View enrolled courses
- Track course progress
- Update learning progress
- View completed courses
- View profile information
- Logout functionality

### 👨‍💼 Admin Features

- Admin authentication
- Admin dashboard
- View platform statistics
- Add courses
- Edit courses
- Delete courses
- View students
- View enrollments
- Manage course information
